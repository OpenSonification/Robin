Explain the map

Robin is an 11 by 11 grid from minus 5 to 5 on both axes. Moving up raises the pitch, and moving left or right moves the sound between your headphones. With VoiceOver off, touch a cell once or drag over the map to hear position tones, then double-tap a cell to plot. With VoiceOver on, first use Turn on VoiceOver controls. Then touch or swipe to focus a cell and hear it without activating it. VoiceOver's double-tap plots the active shape. The focused-cell actions are immediately above the grid. An empty cell plays its position tone on its own; plotted shapes add their sounds on top.

VoiceOver cell actions

These actions apply to the most recently focused grid cell. All actions remain visible. Move VoiceOver focus to an action to select it, then double-tap to run it. The selected button turns blue. Circle is the default active shape. On supported Safari versions, the same commands are also in the Actions rotor while a grid cell is focused.

Touch controls

These controls are for touchscreen phones and tablets. There are no keyboard or directional-arrow controls in this version.

  1. Choose the shape you want to plot.
  2. With VoiceOver off, touch a cell once to hear it. The first touch also starts Robin audio.
  3. Keep one finger down and drag across the map to hear each cell you cross. Double-tap a cell to plot the selected shape.
  4. With VoiceOver on, activate Turn on VoiceOver controls above the grid once. Touch or swipe to focus cells and hear each one without double-tapping. Double-tap only when you want to plot. Use VoiceOver's standard three-finger swipe to scroll the page.
  5. On Safari versions that support web rotor actions, keep focus on a grid cell and rotate two fingers until VoiceOver says Actions. Swipe up or down to choose Delete, Play row, Play column, or a sweep, then double-tap. The visible buttons remain available on every browser.

About Robin

Robin is a sonification and visualisation tool for scatter-plot data and bar charts, built for blind, visually impaired, and sighted users as part of the 195th European Study Group with Industry's Sonification project.

Sound points are plotted on an 11 by 11 grid running from negative five to five on both axes, with zero at the centre. Users can place points individually using circles, squares, triangles, or diamonds, or draw them continuously as sound while moving. The cursor and each plotted shape are also shown on screen, and the audio and visual settings can be adapted to the user's requirements.

Robin was developed using VoiceOver on a MacBook Pro. It has been built and tested on macOS, but should also work on Windows; feedback from people using NVDA or JAWS is welcome. The Sonification team's work was carried out in memory of Dr Robin Williams, with a report on the research currently in development.

How to use it

Arrow keys
Move around the grid from anywhere on the page.
S C T D
Select square, circle, triangle, or diamond.
Shift
Plot the selected shape in the focused cell.
Shift + arrows
Plot the selected shape while moving.
Backspace
Remove the most recently plotted point in the cell.
Backspace + arrows
Delete while moving across the grid.
1
Play the current row from left to right.
2
Play the current column from bottom to top.
3
Play only plotted shapes, one column at a time.
4
Play only plotted shapes, one row at a time.
Space
Turn the screen black or restore the graphics.
Tab
Jump to the next plotted point; Shift+Tab goes back.
0
Return to the centre of the grid.
Command/Ctrl + A
Select all points; Backspace then clears them.
Command/Ctrl + Z
Undo one of the last 20 edits.
Command/Ctrl + I
Import x, y, and optional shape columns from CSV.
Control + ,
Open sound, playback, and colour settings.
Escape
Leave the grid and move to the About Robin explanation.
Enter / Space
Use the button that currently has focus.

Headphones make the left-to-right movement easiest to hear.
